# OKF-Vault

Memoria persistente de Hermes Agent. Vault de Obsidian que sigue el estándar OKF v0.1.

## Sub-directorios

* [criteria/](criteria/index.md) - The tests a concept must pass to enter the graph — what counts as actionable, what earns a cyber block, and what stays descriptive.
* [decisions/](decisions/index.md) - The rules this demo graph runs on: configurable versus hardcoded, when a cyber block is mandatory, files before ingest, and how a reversed decision retires.
* [frameworks/](frameworks/index.md) - The theoretical ground of the graph — cybernetics, requisite variety, second-order observation, and typed edges as the ontology that keeps agent reasoning inside the domain.
* [glossary/](glossary/index.md) - The vocabulary that makes the control loop concrete: sensor, perception, actuator, outcome, review_on, edge, vault — each term defined in one sentence and linked to the concept that uses it.
* [insights/](insights/index.md) - What the graph concluded by reading itself: markdown as memory is validated, and the level-2 territory — self-correction with measurement — is still vacant.
* [maps/](maps/index.md) - Where to start reading: the entity map that shows how frameworks ground decisions, decisions apply patterns, and specs implement the format.
* [patterns/](patterns/index.md) - Reusable mechanisms extracted from decisions — starting with retirement: a reversed decision stays visible for provenance but stops being served as truth.
* [plans/](plans/index.md) - The plan this repo implements: a public, self-contained OKF demo with a curated graph, a deterministic level-2 runtime, and a documented path to level 3.
* [projects/](projects/index.md) - The project that ships OKF to the community: the published mcp-okf server, this demo vault as the on-ramp, and the installer that seeds it for new users.
* [scripts/](scripts/index.md)
* [specs/](specs/index.md) - The formal contracts — the OKF v0.1 format (concepts, frontmatter, links, indexes, logs) and the typed-edge architecture that gives the graph its semantics.
