# Open-Source Release

## What ships

1. **mcp-okf** — the server exposing the graph to any MCP client.
2. **okf-demo** — this repo: the curated on-ramp that proves the loop.
3. **install.sh** — one command that installs the CLI and seeds a demo
   vault when the user has none.

## Why now

Ten independent projects validated the pattern; none closed the loop.
This release claims the level-2 position with evidence, not promises. See
[[convergence-of-external-validations]].
