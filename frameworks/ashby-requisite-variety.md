# Ashby's Requisite Variety

Ashby's law: *only variety can absorb variety*. For a control system to
regulate a domain, its internal model must be at least as varied as the
domain it controls.

Applied to a knowledge graph:

- New domains require new concept types, sensors, and actuators.
- A graph that cannot represent a decision being reverted cannot detect it.
- A graph that cannot represent a risk cannot retire it.
- The taxonomy must be configurable — not because it changes often, but
  because the domain it models changes.

This grounds the configurable-vs-hardcoded principle: the core contract
(type + description + wikilinks) is fixed; the vocabulary is not. See
[[cybernetic-graph]] and [[configurable-vs-hardcoded]].
