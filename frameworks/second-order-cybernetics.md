# Second-Order Cybernetics

Second-order cybernetics (von Foerster) studies systems that include the
observer in the description. Applied to a knowledge graph:

- The graph's own structure is part of what it models.
- Read operations are feedback: every read changes the graph's state.
- The document describing the framework is itself a node subject to the
  same review, staleness, and correction loops.

This is what separates a cybernetic graph from a wiki. A wiki holds notes.
A second-order system holds notes about itself, and acts on them.
