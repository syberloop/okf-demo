# Memory Stores vs Modeling

## Observation

A memory stores facts and waits to be asked. A model of reality is a
living structure: it senses when the world moved past it, decides whether
a recorded truth is still true, and corrects itself.

The difference is not retrieval quality. It is judgment.

- Level 0: the format (markdown as memory).
- Level 1: the pattern (agents read and write it).
- Level 2: the system that notices its own mistakes and closes the loop —
  sensors, decisions, actuations, measurement.

Almost every project in the space ships levels 0 and 1. Level 2 is the
unclaimed territory. See [[convergence-of-external-validations]] and
[[cybernetic-graph]].
