# Insights


## Guías Disponibles

* [convergence-of-external-validations.md](convergence-of-external-validations.md) - In three weeks, ten independent projects converged on the same pattern: markdown as memory for AI agents. All ship storage (levels 0/1). None ships self-correction with measurement (level 2). The pattern is validated; the level-2 territory is vacant.
* [explicit-vs-implicit-memory.md](explicit-vs-implicit-memory.md) - Implicit memory (raw capture, screen recording, transcripts) and explicit memory (a curated semantic graph with control loops) operate on different layers. The threat is commoditization of the capture layer, not the capture tools themselves. What stays differentiated is semantic structure and closed loops.
* [memory-stores-vs-modeling.md](memory-stores-vs-modeling.md) - The question is not how to organize what you know, but how to build a system that knows what it does not know and acts to find out. Storage is level 0; a model of reality that corrects itself is level 2.
