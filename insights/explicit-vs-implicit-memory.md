# Explicit vs Implicit Memory

## Observation

Two layers of memory for agents:

- **Implicit**: raw capture — screen recordings, transcripts, everything
  the user did. High recall, low structure.
- **Explicit**: a curated graph — decisions, lessons, risks with typed
  edges and control loops. Low volume, high judgment.

They are complementary, not competing. The capture layer is rapidly being
commoditized; the semantic layer is not. What compounds is not how much
you record, but what the system decides about what it recorded. See
[[memory-stores-vs-modeling]] and [[cybernetic-graph]].
