# Cyber Eligibility

## Rule

A concept qualifies for the `cyber` block only when it is an actor in
the loop — something decided, planned, executed, or measured. The
eligible types are **Decision, Plan, Project, and Insight**. Descriptive
or reference concepts never carry a cyber block.

## Why

The cyber block is a measurement instrument, not decoration. If every
concept carried one, the review cycle would drown in noise and the
signal would disappear: a framework has no outcome. The eligibility rule
keeps the loop meaningful. See
[[cyber-block-for-actionable-concepts]].
