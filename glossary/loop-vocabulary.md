# Glossary

| Term | Definition |
|---|---|
| **Vault** | A folder of markdown files that IS the graph. See [[file-first-over-ingest]]. |
| **Concept** | A node: a markdown file with frontmatter. See [[okf-v01]]. |
| **Edge** | A typed relationship between two concepts. See [[typed-edges-as-ontology]]. |
| **Sensor** | Something that detects state: a review date, a broken link, a drift signal. |
| **Perception** | The interpretation of what a sensor signal means. |
| **Actuator** | Something that executes a correction: an index regeneration, a retirement, a commit. |
| **Outcome** | The recorded result of an actuation: success, failure, or pending. |
| **review_on** | The scheduled date when a concept must be re-evaluated. |
| **Cyber block** | The frontmatter block that turns a note into a loop participant. See [[cyber-block-for-actionable-concepts]]. |
| **Retirement** | Marking a reverted decision as no-longer-truth while preserving it. See [[retirement-mechanism]]. |
